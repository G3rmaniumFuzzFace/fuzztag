# fuzztag
FuzzTag: a notepad-style prompt editor for ANIMA / Illustrious. Live Danbooru tag autocomplete, auto-cleanup (underscores, brackets), weight control, tag colors, drag-to-reorder and auto-sort. Works on PC and phone, no install needed.
